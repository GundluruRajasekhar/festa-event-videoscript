Festa

Festa turns a few details about your event into a budget, a timeline, a vendor checklist and ideas to start with.

Run it

Open index.html in any modern browser. No install or build step is needed.

How to use it

  1. Choose wedding, birthday or community event.
  2. Enter guests, budget and date.
  3. Select Create my plan.
  4. Review the budget, follow the timeline, tick vendors as you book them, and pick from the ideas.
